OCHA Centre for Humanitarian Data

SEAS5 Precipitation Alerts

Every month ECMWF issues SEAS5, a seasonal rainfall forecast for the six months ahead. This work turns it into drought and flood alerts a response can act on: skill-gated, expressed as return periods, and joined against humanitarian caseloads.

The app

ECMWF SEAS5 precipitation alerts

The latest issuance's drought and flood signals by country and admin unit — return periods, forecast skill, history, and the Forecast × HNRP overlay joining the forecast to response-plan caseloads.
