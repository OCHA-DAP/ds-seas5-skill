How the forecast alerts are calculated

Each country is shaded by where the latest CMA CMME (China Meteorological Administration, China Multi-Model Ensemble) seasonal precipitation forecast sits within its own forecast history, but only where the forecast has demonstrated skill against observations. The method is identical to the SEAS5 version of this site, applied to the CMME forecasts at country level (CMME's native 1° grid is aggregated to country averages; there is no pixel view).

1. Data

  • Forecast: CMA CMME ensemble-mean precipitation on a 1° grid, monthly leads 1–6. The record is a 1991–2020 hindcast plus real-time issuances from August 2025 — there are no issuances between January 2021 and July 2025. The hindcast's spatial mask (ocean cells) is applied to the real-time fields so both aggregate over identical cells.
  • Observations / climatology: ERA5 reanalysis precipitation, same countries and period.

2. From a forecast to an anomaly category

  1. Aggregate to the trimester. For a given issue month, the monthly forecast is averaged over the 3-month target season (e.g. a June issue → Jul–Aug–Sep), giving one forecast value per year. ERA5 is aggregated the same way (complete seasons only). CMME does not forecast the issue month itself, so only fully-future trimesters (leadtimes 1–4) are available — unlike the SEAS5 site, there are no in-season (already-started) trimesters.
  2. Transform, normalise & detrend. Values are log-transformed, and the forecast is rescaled to match the ERA5 mean and spread, so the two are comparable. A linear trend is then removed from both the forecast and the observations (in log space, keeping each series' mean) — so the forecast is judged against recent conditions rather than the full historical range.
  3. Locate the forecast. The forecast's percentile within the historical forecast distribution is computed, along with an empirical (Weibull) return period — how often a forecast this dry (or this wet) has occurred.
  4. Categorise. Below 50th percentile → drought side, above → flood side. The band depends on the return period (see defaults below).

3. Skill

Skill is the temporal Pearson correlation (r) between the normalised, detrended hindcast forecast and ERA5 observations across the record (1991–2020, plus any completed real-time seasons). Countries are only alerted where the forecast is skilful:

  • High skill: r ≥ 0.50 — solid fill.
  • Moderate skill: 0.30 ≤ r < 0.50 — hatched fill.
  • Low skill: r < 0.30 — no alert (cross-hatch / neutral).

There is no single official correlation cut-off: WMO's SVSLRF guidance recommends judging significance locally rather than a fixed value. The defaults are chosen so that 0.30 ≈ the 95% statistical-significance level for a ~30-year hindcast, and 0.50 ≈ "useful" skill (r ≈ 0.5 explains ~25% of variance; IRI/Tippett et al. 2010 note RPSS ≈ 0.1 corresponds to r ≈ 0.44).

Skill also depends on leadtime — how far ahead the forecast is issued. For a trimester, leadtime is the number of months from the issue month to the trimester's first month (a June issue → Jul–Aug–Sep is leadtime 1), and skill generally decays as leadtime grows. CMME's monthly forecasts run 1–6 months ahead and do not cover the issue month, so trimester leadtimes go from 1 to 4 — beyond that a 3-month trimester would extend past the forecast horizon. The Skill map and Skill by country tabs show r for every trimester and leadtime, coloured at these same cutoffs (with negative r shown as its own category).

4. Rainy-season (in-season) selection

A country–trimester is treated as in season when that trimester carries a meaningful share of the annual rainfall — by default, the trimester mean is ≥ 15% of the annual total (with no additional per-month minimum). By default the map only shows alerts for in-season trimesters; the “Show alerts outside rainy season” toggle reveals the rest.
